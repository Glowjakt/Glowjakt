# Glowjakt

Price comparison for beauty products in Sweden, Norway, Denmark and Finland. Prices are collected from online stores every morning, and the same product is matched across stores by its barcode (EAN). Stores cannot pay for listing or placement.

Remote MCP server for AI assistants: `https://mcp.glowjakt.se/mcp` (Streamable HTTP, no authentication).
